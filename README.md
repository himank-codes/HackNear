# HackNear 🚀

HackNear is my first web development project. It is a website designed to help students discover hackathons and manage their participation.

## Features
- Browse hackathons
- Search and filter events
- Bookmark hackathons
- Create teams and manage friends
- Dark mode
- Responsive design

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Note
This is my first project and is currently a front-end prototype. Hackathon listings are sample data, and registrations and team features are demo functionality.
